# WisKey 0.32 — שדות ברשימה והרשאות מקבוצות

## תצוגת המשתמשים

כל שדה מותאם פעיל מוצג כעמודה בשמו המוגדר ברשימת המשתמשים. בנייד מוצגים שם השדה והערך בכרטיס המשתמש. גם שמות הקבוצות מוצגים. ערך חסר מסומן בקו מפריד, ושדות כבויים מוסתרים. שינוי שם השדה שומר את הערכים הקיימים. בטבלה רחבה ניתן לגלול בתוך אזור הטבלה; תוכן הדף עצמו אינו חורג מהרוחב.

## הגדרת קבוצות ושיוך משתמשים

1. עבור אל **כלי ניהול → אפשרויות פרטי משתמש → קבוצות**.
2. צור קבוצה כגון הנהלה או אחזקה, ובחר את דלתות התחנות שמותרות לה.
3. שמור. השינוי חל על כל חברי הקבוצה ונוסף לסנכרון לתחנות. קבוצה חדשה ללא דלתות אינה מקנה גישה.
4. בעריכת משתמש, סמן קבוצה אחת או כמה קבוצות. בחירת הדלתות מתעדכנת בטיוטה; ההרשאות בפועל נשמרות רק בשמירת המשתמש.

המערכת עדיין מנהלת רק את הממסר הפעיל שאומת בכל תחנה. תחנה שמוגדרת כמצלמה בלבד אינה ניתנת להוספה לקבוצה. ניתוק רשת זמני אינו מבטל את הגדרת התחנה או את ההרשאות הרצויות.

## כללי הרשאה וחריגות אישיות

ההרשאות מחושבות כך: **איחוד דלתות הקבוצות הפעילות וההרשאות האישיות, פחות החסימות האישיות**.

- אדם בקבוצות הנהלה ואחזקה מקבל את הדלתות של שתיהן.
- סימון דלת בעריכת המשתמש יוצר הרשאה אישית. ביטול הסימון יוצר חסימה אישית שגוברת גם על כמה קבוצות שמקנות את אותה דלת.
- ליד כל דלת מופיעים מקור ההרשאה ושמות הקבוצות הרלוונטיות.
- **חזרה להרשאות הקבוצה** מסירה את החריגה בדלת אחת. **ביטול כל החריגות האישיות** מחזיר את כל הדלתות לחישוב לפי הקבוצות בלבד. הפעולות נשארות בטיוטה עד שמירה.
- הסרת משתמש מקבוצה או הסרת דלת מקבוצה מבטלת רק את הגישה שנבעה מאותו שיוך. קבוצה אחרת או הרשאה אישית עשויות להמשיך להקנות גישה.
- השבתת קבוצה מבטלת את ההרשאות שהיא מקנה, ושומרת את חברות המשתמשים בה. הפעלתה מחדש מחילה מחדש את הרשאותיה. הרשאות וחסימות אישיות נשמרות.
- משתמש לא פעיל או שתוקפו פג אינו מקבל גישה בזכות קבוצה; כללי התוקף והאימות הקיימים נשארים בתוקף.

הרשאות קיימות מהגרסה הקודמת נשמרות כחריגות אישיות. כדי להעביר משתמש קיים לניהול לפי קבוצות בלבד, שייך אותו לקבוצות המתאימות, לחץ על ביטול כל החריגות האישיות, בדוק את הדלתות ושמור.

## שמירה, סנכרון ושחזור

הגדרות השדות והקבוצות עוברות מקובץ הפרופיל הנפרד לתוך מאגר הגישה המרכזי בסכמה 5. הגדרות 0.31 נקראות פעם אחת, ונשמרות יחד עם הרשאות המשתמשים באותה פעולה אטומית. לאחר המעבר, הקובץ הישן אינו מחליף את ההגדרות המרכזיות. סיסמאות, כרטיסים, תמונות, שיוכים, בעלות בציוד ותורי מחיקה נשמרים.

שינוי הרשאות קבוצה שומר באותה פעולה את הגדרתה ואת ההרשאות המחושבות של כל המשתמשים שהושפעו. כשל בשמירה אינו מחיל חלק מהקבוצה. שינוי שם בלבד אינו יוזם סנכרון משתמשים. שינוי פרטי קבוצה בזמן שעריכת משתמש או סקירה קבוצתית פתוחה מחייב סקירה מחדש; חלון ישן אינו רשאי לדרוס מדיניות חדשה.

ביטול גישה בתחנה מנותקת נשאר בתור השחזור הקיים. אתחול HA אינו מאבד את הבעלות או את בקשת הביטול. הסנכרון לשאר התחנות ממשיך כרגיל. השינוי נחשב מאומת בציוד רק לאחר קריאה חוזרת, כפי שהיה עד כה. שינויים בהרשאות המשתמשים נרשמים ביומן המנהל, עם מקור הפעולה ושדות שהשתנו וללא קודים או תמונות.

ייבוא CSV ופעולות קבוצתיות ממשיכים לעבוד עם הרשאות הדלתות בפועל. שינוי דלת אחת שומר חריגות קיימות בדלתות שלא השתנו. מתן או ביטול גישה דרך הממשקים האלה נבחן מול מדיניות הקבוצות; ביטול גישה מורשת נשמר כחסימה אישית.

יש לשמור גיבוי Home Assistant לפני שדרוג. גרסה ישנה אינה יכולה לקרוא מאגר בסכמה 5; חזרה לגרסה ישנה מחייבת גם שחזור הגיבוי התואם.

## אימות ושחרור

הבדיקות מכסות איחוד קבוצות, חסימה והוספה אישית, חזרה לירושה, השבתת קבוצה, שינוי שם ללא כתיבה נוספת, שמירה שנכשלה או בוטלה, עריכה מיושנת, הגירת הרשאות קיימות, שמירת חריגות דרך CSV/פעולות קבוצתיות, ביטול בתחנה מנותקת ואתחול לפני חזרתה. נכתבו בדיקות HA להרשאות מנהל, שמירה מרכזית והעברה מקובץ הפרופיל הקודם; הן עברו כחלק מחבילת 304 בדיקות HA ב־CI. בדיקות דפדפן מכסות עמודות מותאמות, קבוצות, בקרות הרשאה, עברית, מובייל ושני העיצובים.

בדיקות הפרוטוקול משתמשות בתחנות מדומות עם מנוע הסנכרון הקיים. לא הוגדרו קבוצות או שונו הרשאות בתחנות ההתקנה של הבעלים במסגרת הפיתוח.

פורסמה [v0.32.0-alpha.1](https://github.com/jonioliel/home-assistant-hikvision-intercom/releases/tag/v0.32.0-alpha.1) מהקומיט `e5f50a10bd93d23b28b40de8312b9a333d040e8a`. מימוש הרשאות הקבוצה שמור ב־`6179b01`, ותיקון העיצוב והתיעוד ב־`e5f50a1`.

[כל שבעת שערי השחרור](https://github.com/jonioliel/home-assistant-hikvision-intercom/actions/runs/34488590232) עברו: **934 בדיקות Python בכל גרסה (3.12/3.14), 304 בדיקות Home Assistant ו־322 בדיקות דפדפן**, וכן Ruff, עיצוב Python, mypy, TypeScript, Prettier, בנייה זהה של החבילה, HACS ו־Hassfest. התג, ה־manifest, הפאנל ו־AudioWorklet אומתו מול הקומיט שנבדק. [ראיות הפרסום](evidence/release_0.32.0-alpha.1.json).

בריצה המקומית עברו 933 בדיקות ליבה ו־322 בדיקות דפדפן. בדיקת עומס הקול שלא הורצה בסבב Windows המקומי עברה בשתי ריצות Python המלאות ב־CI, ללא הקלת מגבלת הזמן או תנאי הבדיקה. כשל עיצוב קוד שנמצא בריצה הראשונה תוקן לפני הפרסום. חסימת ההעלאה הקודמת נפתרה באישור מפורש נוסף מהבעלים.

לעדכון: שמור גיבוי Home Assistant, התקן את `v0.32.0-alpha.1` דרך HACS ואתחל את HA. לאחר מכן הגדר דלתות לקבוצות בכלי ניהול ושייך משתמשים. עבור משתמשים קיימים, סקור את החריגות האישיות שנשמרו מהגרסה הקודמת לפני מעבר להרשאות קבוצה בלבד.
