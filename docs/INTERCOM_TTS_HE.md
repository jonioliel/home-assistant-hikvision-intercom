# הקראת הודעות באינטרקום באמצעות Home Assistant TTS — WisKey 1.8.0

WisKey יכול להשתמש במנועי ה־TTS שכבר הוגדרו ב־Home Assistant, לרבות Google Translate TTS, כדי להקריא טקסט ברמקול של תחנת אינטרקום נבחרת.

## שימוש

1. פתח את המצלמה של התחנה הרצויה.
2. בחלק **הודעה קולית באינטרקום** הקלד הודעה באורך של עד 500 תווים.
3. בחר מנוע קול ושפה. בממשק עברי, `iw` נבחר אוטומטית כאשר המנוע מפרסם תמיכה בעברית.
4. לחץ **השמע בתחנה**. הממשק יציג יצירה, השמעה והשלמה.
5. ניתן ללחוץ **עצור הודעה** כדי להפסיק שידור שעדיין פעיל.

ההודעה נשלחת רק לתחנה שחלון השיחה שלה פתוח. סגירת החלון, מעבר האפליקציה לרקע, ניתוק Home Assistant, סיום שיחה או הסרת התחנה מפסיקים את ההשמעה.

## הגדרת Google TTS

יש להגדיר תחילה את Google Translate Text-to-Speech ב־Home Assistant. WisKey מגלה בזמן אמת את ישויות `tts.*` ואת שפות המנוע, ואינו דורש להזין מזהה ישות בקוד או לשמור פרטי ספק.

מסמכי Home Assistant הרשמיים:

- [Google Translate Text-to-Speech](https://www.home-assistant.io/integrations/google_translate)
- [Text-to-speech](https://www.home-assistant.io/integrations/tts)

אם לא נמצא מנוע, לחצן השליחה מושבת ומוצגת הנחיה להגדיר מנוע TTS ב־Home Assistant.

## מסלול האודיו

Home Assistant יוצר WAV מועדף של 8kHz, ערוץ יחיד ו־16 ביט. WisKey מאמת את הקובץ, מגביל אותו ל־60 שניות, ממיר אותו ל־G.711 μ-law ומזרים מנות של 100ms דרך ערוץ `ISAPI/System/TwoWayAudio/channels/1` שכבר אומת לדיבור מהמיקרופון.

המערכת אינה מפעילה ממסר, אינה משנה משתמש או הרשאה ואינה שומרת את הטקסט בהיסטוריה. הטקסט, כתובת המדיה ותשובת הספק אינם נכתבים ללוגים. קובץ האודיו נשמר בזיכרון רק למשך ההשמעה.

## בעלות, הרשאות ובטיחות

- נדרשת הרשאת **ניהול** לסקירה או לתחנות; הרשאת צפייה בלבד אינה מספיקה.
- תחנה יכולה להחזיק ערוץ דיבור אחד: מיקרופון פעיל והודעת TTS אינם פועלים במקביל.
- חיבור דפדפן אחד אינו יכול להפעיל כמה ערוצי שמע במקביל, והמכסה הכללית היא שלושה ערוצים.
- מנוע שאינו מוגדר ב־Home Assistant נדחה בצד השרת.
- יצירת קול מוגבלת ל־30 שניות; ההשמעה מוגבלת לדקה.
- הצלחת ה־HTTP והעברת המנות מאמתות את המסלול הטכני. שמיעה בפועל ברמקול היא בדיקת מסירה פיזית.

## תקלות נפוצות

- **אין מנוע קול:** בדוק שקיימת ישות `tts.*` פעילה ב־Home Assistant ואתחל את WisKey לאחר התקנת האינטגרציה.
- **השמע תפוס:** סגור דיבור פעיל או הודעה קודמת באותה תחנה ונסה שוב.
- **הפקת הקול נכשלה:** בדוק קישוריות של Home Assistant לספק ה־TTS והשפה שנבחרה.
- **פורמט לא נתמך:** מנוע ה־TTS לא סיפק את WAV המועדף לאחר עיבוד Home Assistant. הורד אבחון ללא תוכן ההודעה ופתח תקלה.
- **תחנה לא זמינה:** ודא שהתחנה מחוברת ושבדיקת הזהות שלה עברה.

## אימות

בדיקות הקוד מכסות גילוי מנועים, עברית בנייד, הרשאות, ניתוק, עצירה, התנגשות עם מיקרופון, הגבלת טקסט, סודיות לוגים והמרת WAV ל־G.711. את השמיעה הפיזית בתחנה יש לסמן בדף [בדיקות 1.8.0](manual-tests/WISKEY_1.8.0_TESTS_HE.html).
