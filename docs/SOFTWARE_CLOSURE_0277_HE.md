# סגירת פערי תוכנה — 0.27.7-alpha.1

הבקשה: להשלים את העבודה שאפשר לקדם ללא בדיקות פיזיות. המפרט נקרא מחדש במלואו,
ונבדקו החבילות A–F בתוכנית 95% מול המימוש, הראיות ותוצאות הבדיקות הקיימות.
הגרסה מרכזת תיקוני תוכנה נוספים; היא אינה מסמנת בדיקות שטח כאילו הושלמו.

## מה הושלם

| תחום | תוצאה |
| --- | --- |
| תוקף משתמש | רענון שעון תחנה/HA והסרת תחנה אינם מזיזים בשקט את רגעי התוקף. נשמרים גם שניות ורגע ידוע בשעה חוזרת. |
| טיוטת זמן שגויה | טווח לא חד־משמעי מתנקה גם בשדות עצמם ומוצג הסבר להזנה מחדש. |
| סינון אירועים | שינוי אזור ברקע או מעבר תחנה שומרים את רגעי הסינון; דוחות קיימים ממשיכים להשתמש במסננים שכבר הוחלו. |
| יומן שינויים | שינוי אזור HA אינו מפרש מחדש תאריכים קיימים כחלון אחר. |
| הסרת PIN | שדות קוד חלופי ואימותו מתרוקנים בפועל; אפשר להשאיר את הקוד השמור בלי שהטיוטה שנזרקה תישאר בשדות. |
| פעולה קבוצתית | קריאה מוגבלת ל־30 שניות ושמירה ל־60. אחרי תשובה שאבדה נשמר מזהה הפעולה לבדיקת אישור השמירה. |
| ניווט וניתוק | חזרה למסך משתמשים באותו חיבור משחזרת מעקב אחר הפעולה. החלפת מנהל או חיבור אינה מעבירה תוצאה פרטית מההקשר הקודם. |
| אי־ודאות בשמירה | אין שליחה חוזרת אוטומטית. אישור חסר עדיין אינו הוכחת כשל; אפשר לבדוק שוב או לרענן ולסקור פעולה חדשה. |
| מסכי תכנון | זמני המתנה מוגבלים, ביטול המתנות מקומיות בניתוק, טעינה חדשה בחיבור שהוחלף והתעלמות מתשובות ישנות. |
| מאגר פרטי | קובץ שחורג מ־32 MiB כולל מעטפת UTF-8 נדחה לפני החלפת הקובץ התקין; הודעת Repairs נשארת עד שמירה מוצלחת. |

התאוששות מפעולה קבוצתית נשמרת בזיכרון החיבור במהלך ניווט במסכים. לאחר טעינת דפדפן
מלאה משתמשים ברשימת הפעולות השמורות ובנתוני המשתמשים; לא נשמרים PIN או משתמשים ב־localStorage.
בדיקת אישור השמירה בשרת משויכת למנהל שיזם אותה. עצירת המתנה בדפדפן אינה מבטלת
פעולה שכבר התחילה בשרת.

## בדיקות וראיות

שוחזרו לפני התיקון: חמישה כשלי תוקף, שני כשלי ניקוי PIN, שבעה כשלי פעולות קבוצתיות,
חמישה כשלי סינון זמן ושבעה כשלי תכנון. נוספו גם בדיקות לבידוד מנהלים, פינוי מאזינים,
אישור חסר ושימור רגע ידוע בשעה חוזרת. בבדיקת HA לפני תיקון השמירה התקבלו ארבעה כשלים
מכוונים ו־274 בדיקות שעברו ([הרצה](https://github.com/jonioliel/home-assistant-hikvision-intercom/actions/runs/34442306205)).
בדיקת יומן השינויים תוקנה תחילה לפתיחת אזור המסננים; לאחר מכן שוחזרה סטיית הזמן עצמה.

פורסמה [v0.27.7-alpha.1](https://github.com/jonioliel/home-assistant-hikvision-intercom/releases/tag/v0.27.7-alpha.1) מהקוד `fc70d2088acb4092e078d13993b1f40c6277b138`.
[כל שבעת שערי הפרסום](https://github.com/jonioliel/home-assistant-hikvision-intercom/actions/runs/34443660814) עברו: **887 בדיקות Python בכל גרסה (3.12/3.14),
278 Home Assistant ו־256 דפדפן**, לצד mypy על 57 קבצים, Ruff, TypeScript,
Prettier, שחזור חבילת הממשק, HACS ו־Hassfest. התג, manifest, הפאנל ו־AudioWorklet
אומתו מול הקוד שנבדק. [ראיית פרסום מלאה](evidence/release_0.27.7-alpha.1.json).
נוספו **34 בדיקות רגרסיה** ביחס ל־0.27.6: ארבע HA ושלושים בדפדפן.

קומיטי המימוש: `5fbc105`, `cde5e29` (תוקף זמן), `c7e3dd1` (PIN),
`ce32879` (פעולות קבוצתיות), `d2f74b3` (מסננים ושמירה), `0cb3b50` (תכנון),
`fc70d20` (אריזת הגרסה והתיעוד). קומיטי הבדיקות ששחזרו את הכשלים נשמרו לפניהם.

לעדכון: ב־HACS בחר 0.27.7-alpha.1, הורד והפעל מחדש את Home Assistant.
לאחר רענון הפאנל מספר הגרסה המוצג צריך להתאים. סכמה 3 נשארה ללא שינוי.

## מה נשאר ומה נדרש להמשך

| חבילה בתוכנית | מה כבר קיים | מה עדיין מונע סגירה |
| --- | --- | --- |
| A1 — זהות באירוע PIN | נרמול, התאמה מוגבלת לתחנה, הצגת סיבת זהות חסרה וכלי חקירה. | דגימת האירוע המקורי או אירוע חדש מתואם שבו נצפה אותו כשל. אין זיהוי אדם על פי סמיכות זמן או קוד. |
| A2 — חלון תוקף | UTC, אזור תחנה/HA/ידני, בדיקות DST והגנת סתירה מול המכשיר. | פתרון הסתירה בפורמט הקושחה ובדיקה לפני/בתוך/אחרי חלון הרשאה. |
| A3/A4, B2 — צלצול ושיחה | איסוף אירועים, נרמול, פקדים, הפרדת תחנות ושחזור היסטוריה. | יעד חיוג תקין ורצף צלצול/תפוס/ביטול/מענה פיזי; אישור API לבדו אינו ראיית מענה. |
| B1 — WebRTC | איתות, ניגון, מדדים ומעבר מסומן למסלול וידאו חלופי. | גישה מורשית ל־HA ולדפדפן של ההתקנה, והשלמת תיקון הרשת/NAT. אפשר לבדוק מרחוק כשאלה זמינים. |
| B3/B4 — שמע | מנהל סשן, תעבורה, האזנה ולחיצה לדיבור; קיימות ראיות סשן ותעבורה קודמות. | אישור שקול נשמע בפועל בשני הכיוונים. |
| C1–C6 — ממשק | המסכים, הסגנון המשותף, RTL/LTR, מובייל, מקלדת ובדיקות חזותיות קיימים. | משוב שימוש על המערכת המותקנת; תקלות שיתגלו יתוקנו לפי הממצא. |
| D — כרטיסים ומעבדה | CRUD, רישום בקורא, CSV, סנכרון, ביטול ותפוגה נבדקו בתוכנה. | מחזור כרטיסים מלא והשלמת מטריצת המעבדה. בדיקות PIN והמחיקה שכבר אישרת נשארות מאושרות. |
| E — צי | הפרדת תשע תחנות, תורים, התאוששות ושחזור נבדקו במדמה. | קבלת תשע תחנות אמיתיות והרצה ממושכת בחלון מתואם. |
| F — מסירה | SemVer, CHANGELOG, HACS, שדרוג ומיגרציות, בדיקות ופרסום אוטומטי. | קבלת התקנה/שדרוג של הבעלים וסגירת תנאי השטח לפני v1 סופית. |
| Phase 6 — לוחות זמנים ו־NFC | תכנון ובדיקות קריאה קיימים; כתיבת הרשאות שעות בציוד אינה מופעלת. | חוזה יכולות וכתיבה מאומת לקושחה; ל־NFC נייד טרם נמצא חוזה נתמך. לא מנחשים API כדי לסמן השלמה. |

לא נותרה בחבילה זו משימת מימוש ידועה שניתן להשלים על החוזים המאומתים בלי אחת מהתלויות
המתוארות. זו אינה טענה שלא יתגלו תקלות נוספות בהתקנה או ש־Phase 6 הושלם.
