# המשך סבב התפעול — 2.0.0-rc.13

בהמשך לסדר **5 → 1 → 2 → 4 → 3**, הסבב הנוכחי מקדם את ניהול הגישה הזמנית. מסירות בריאות הצי, האירועים, הרשאות המפעילים והמדיה מפורטות ב־[דוח rc.12](OPERATIONS_SPRINT_PROGRESS_2_0_RC12_HE.md) ונשמרות בגרסה זו.

| מסירה | אימות תוכנה | מה נשאר |
| --- | --- | --- |
| מעקב ייעודי לאורחים ולקבלנים, אחראי, מטרה, תקופת תוקף וסינון | סיווג תחילה/פקיעה/השבתה, סיכום מלא ודוח מוגבל ללא סודות | נוחות ותוצאה על הנתונים של האתר |
| חידוש תוקף עם סקירת לפני/אחרי ואישור | המרת אזור זמן, עדכון תאריכים בלבד, revision, שמירת אמצעי הגישה, כללי שעות, מצב פעיל ודלתות | אישור כניסה פיזית בתוך הטווח ודחייה בסיום |
| חיבור למסלול הסנכרון וליומן | אותו `users/update`, זיהוי מפעיל ובקשת סנכרון אחרי שמירה | השלמה לתחנות האמיתיות ובדיקות המתנה |
| הרשאות והתאוששות | צופה אינו מחדש; מפעיל ניהול משתמשים מורשה; תגובה מאוחרת אינה מעדכנת הקשר חדש | בקשת חידוש חיצונית ואישור מארח נפרד |

לא נוספו צ'ק־אין/יציאה, אישור דו־שלבי או הודעות אוטומטיות. אלה נשארים בתוכנית. אין שינוי דומיין, נתיב HACS או אחסון; בחירת וידאו חי ללא קול או תמונה מתרעננת נשמרת.

[דף הבדיקות המעודכן](manual-tests/WISKEY_2.0.0_RC13_TEMP_RENEWAL_TESTS_HE.html) כולל ארבע בדיקות קצרות ומפנה לבדיקה מצטברת. רק תוצאות שהבעלים מסר ייחשבו לאישור ציוד פיזי.
