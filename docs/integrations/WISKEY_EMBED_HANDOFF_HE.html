גרסה 2.0.0-rc.19 · חוזה הטמעה 1

מסכי WisKey בתוך SMPLWISE VMS

ממשק הטמעה וניווט יציב למסכים הקיימים, בזהות המשתמש המחובר לתשתית המערכת.

קבצים להעברה למפתח

מפרט מלא והוראות לפיתוח VMS דוגמת חיבור JavaScript אישור מימוש והיקף האימות

איך מתחברים

  1. מעדכנים את WisKey מתוך שחרור rc.19 לאחר מעבר בדיקות השחרור, ומשלימים הפעלה מחדש וטעינת ממשק.
  2. בתוסף VMS טוענים iframe באותו מקור דפדפן, עם הכתובת הבאה.
  3. נרשמים להודעות לפני טעינת המסגרת; בונים ניווט לפי wiskey:ready.
  4. מחליפים קריאות למתודות פנימיות ב־wiskey:navigate; משקפים את המיקום שאושר מתוך wiskey:location.
/hikvision-intercom?embed=1&tab=users
/hikvision-intercom?embed=1&tab=tools&tool=media_options

אין להעביר למסגרת אסימון שירות. משתמש ללא הרשאות נוספות ממשיך לקבל רק את המסכים והפעולות המותרים לו. הכניסה הרגילה ל־WisKey שומרת על הסרגל הקיים.

מה נותר לבדוק בצד VMS

  • סרגל אחד, ניווט וקישורים ב־Ingress בפועל, במחשב ובנייד.
  • מנהל ומשתמש מוגבל, פתיחה וסגירה של המודול וחזרה אליו.
  • תצוגת מצלמה ושמע במסגרת המקוננת בהתאם להרשאות הדפדפן והתשתית.

המימוש בצד WisKey נבדק אוטומטית. בדיקות אלו נוגעות לחיבור בתוך התוסף הנפרד; הן אינן אישור שה־VMS כבר אימץ את החוזה.

מסמך הבדיקות המרוכז לכל פיתוחי הימים האחרונים ממתין לבקשתך.
