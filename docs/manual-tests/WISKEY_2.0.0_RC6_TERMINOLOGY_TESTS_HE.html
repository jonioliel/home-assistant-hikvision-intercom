מינוח אחיד בממשק

בדיקה קצרה לאחר עדכון והפעלה מחדש של תשתית המערכת.

מה נבדק אוטומטית

נבנה ממשק מעודכן, אומתו קובצי התרגום, ובדיקות הדפדפן כיסו הרשאות, שעונים, מצלמות, שמע, TTS, תוכניות שעות והודעות ניתוק. המזהים הטכניים נשארו ללא שינוי.

בדיקות קצרות אצלך

אם משהו אינו תואם

שלח את שם המסך והנוסח המדויק שמוצג. אין צורך לשלוח סיסמאות או פרטי גישה. מסכי התשתית הכלליים שמחוץ ל־WisKey עשויים להשתמש במיתוג עצמאי.

הסימונים נשמרים בדפדפן זה בלבד. בדיקות וידאו חי מהגרסה הקודמת.
