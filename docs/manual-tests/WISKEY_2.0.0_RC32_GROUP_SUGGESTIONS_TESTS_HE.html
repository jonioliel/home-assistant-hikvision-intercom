rc.32 — הצעות שיוך לקבוצות

בוצעו בדיקות תוכנה; אין צורך לחזור על כל בדיקות הגרסאות הקודמות. אין לבצע שינוי הרשאות של עובד אמיתי לצורך בדיקה.

1. התאמה ברורה

באדם בדיקה שמור בעל מחלקה/תפקיד, פתח סקירת הצעות. בחר שדות והשווה לקבוצה שאנשים פעילים אחרים בעלי אותם ערכים משויכים אליה. ודא שהקבוצה, יחס ההתאמה והדלתות מוצגים בצורה ברורה.

2. עריכה לפני שמירה

בחר קבוצה ואשר את הסקירה. ודא שהקבוצה נוספה לעריכה בלבד, שחסימה אישית ותוקף נשמרו ושהרשאה לא נשמרה לפני לחיצה על שמירה. אפשר לבטל את העריכה.

3. חשבון מוגבל ונייד

בדוק שההצעות כוללות רק קבוצות ושדות שהחשבון רשאי לראות, שאין גלילה אופקית בנייד ושכפתורי האישור נגישים. שינוי עריכה פתוח צריך לדרוש שמירה לפני סקירה חדשה.
