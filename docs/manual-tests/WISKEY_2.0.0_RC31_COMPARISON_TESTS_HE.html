קבלה ממוקדת — השוואה rc.31

הרשאות, מקורות חסויים, סינון ובקשות מאוחרות נבדקים אוטומטית. כאן נשארת התאמה לנתונים שלך, ללא שינוי גישה וללא צורך להיות ליד תחנה.

  1. בכלי הניהול פתח השוואת אנשים וקבוצות. השווה עובד לקבוצה מוכרת ובדוק שהדלתות המשותפות והשונות תואמות להגדרות.
  2. אם לעובד קיימת חסימה או תוספת אישית, בדוק שמקורה מוצג. אם יש דלת שנייה שהוגדרה לו במפורש, בדוק שהיא מוצגת בנפרד.
  3. השווה שתי קבוצות ובדוק את הדלתות החופפות. בדוק בעברית ובנייד שהבחירות והטבלה נוחות ללא גלילה לרוחב.

הכלי משווה שיוכים. הוא אינו מוכיח כניסה בפועל, ואינו מעתיק או משנה הרשאות. מסמך הבדיקות המאוחד עדיין ממתין לבקשתך.
