חידוש גישה לאורחים ולקבלנים

העדכון מוסיף מעקב וחידוש תוקף, אחרי תצוגה מקדימה ואישור. בדיקת כניסה פיזית נשארת שלך; בדיקות התוכנה בוצעו לפני השחרור.

מה כבר נבדק עבורך

סיווג לפי תוקף, כולל רגע הפקיעה; הגבלת גודל הדוח; שמירת PIN, כרטיסים, דלתות וכללי ימים ושעות; יומן שינויים; תזמון סנכרון; חסימת צופה; דחיית עריכה מקבילה; ביטול תגובה מאוחרת; מסך נייד בעברית ותאימות לדוח הישן.

אין צורך לבדוק שוב את כל הגנות התוכנה. ״בתקופת התוקף״ מתאר את התוקף שהוגדר; יש לבדוק את הסנכרון וכללי השעות לפני כניסה בתחנה.

הקטלוג המצטבר של הבדיקות הפתוחות

בדיקה שלא דיווחת על תוצאתה אינה מסומנת כבדיקה פיזית שעברה. בדיקות יציבות והמתנה ממושכת נשארות פתוחות.

דיווח תוצאה

אם משהו נכשל, ציין סעיף, מכשיר, דפדפן ומה קרה. אין לציין PIN, מספר כרטיס מלא או סיסמה.
