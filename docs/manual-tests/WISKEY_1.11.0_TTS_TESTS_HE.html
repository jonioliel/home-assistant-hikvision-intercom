בדיקת הודעות קוליות מהירות

לאחר עדכון WisKey ל־1.11.0, בדוק את השמעת ה־TTS עם תחנה זמינה. בדיקות התוכנה של שמירה, הרשאות, נייד ותאימות לאחור כבר כוסו אוטומטית; כאן נדרש אימות קצר מול הרמקול עצמו.

משפט מהיר נשלח מיד בלחיצה. אין צורך להשתמש בקוד PIN או לשנות הרשאות כדי לבצע בדיקה זו. התוצאות נשמרות רק בדפדפן הזה.
