וידאו חי במרכז הכניסה

בדיקה קצרה במערכת החיה אחרי עדכון HACS והפעלה מחדש של Home Assistant

מה נבדק אוטומטית

בדיקות דפדפן אימתו שנגן חי בכרטיס נשאר מושתק, שכל שטח התמונה פותח את המצלמה, ושהכרטיסים משהים את הווידאו כאשר חלון המצלמה פתוח. עברו גם בדיקות ממשק של 4, 6, 9 ו־12 תחנות ובדיקות מצלמה ושמע. בדיקות אלו אינן מאמתות תנועה או עומס ברשת ובתחנות שלך.

בדיקות אצלך

אם יש בעיה

ציין את שם התחנה, מספר הכרטיסים המוצגים, מחשב או נייד, מצב המדיה שנבחר בניהול (HLS/MSE/RTC), והאם חלון המצלמה המלא מנגן וידאו. אם התנועה נעצרת, ציין בערך אחרי כמה זמן. אין צורך לשלוח סיסמאות או כתובות RTSP.

הסימונים נשמרים בדפדפן זה בלבד. בדיקות TTS מהגרסה הקודמת.
