בדיקות קצרות: תצוגה מקדימה להרשאות

בדיקות כללי ההרשאה ובדיקות הממשק עברו אוטומטית. נותר לוודא שהמסך משקף את בחירתך במערכת המותקנת.

לאחר העדכון

הרשאות בפועל — רק אם ברצונך לבדוק משתמש מפעיל

התצוגה המקדימה מחושבת לפי כללי השרת, אך אינה שומרת הרשאות. הגבלה לפי תחנה או שדה עדיין אינה חלק מהגרסה הזו.

בדיקות קודמות

בדיקות חקירת האירועים, בריאות הצי ובחירת וידאו/תמונה וגישה זמנית נשארות פתוחות.

דיווח תוצאה

אם סעיף נכשל, שלח את המסך, הפעולה, התוצאה שציפית לה ומה שהתרחש. אין צורך לשלוח PIN, מספר כרטיס או סיסמה.

הסימונים נשמרים בדפדפן הזה בלבד.
