rc.35 — חידוש הרשאה אישי

בדיקות קבלה שנשארות בסביבה שלך לאחר בדיקות התוכנה. השתמש בחשבון אישי נפרד ובאדם לבדיקה עם תוקף מוגבל. אין צורך לחזור על כל הבדיקות מהגרסאות הקודמות.

הערות ותוצאות

הוראות הפעלה · מפרט לפיתוח VMS

הבדיקות האוטומטיות כוללות שיוך מחדש, הרשאות, זהות מזויפת, גרסה מיושנת, שמירה שנכשלה ואובדן אישור שליחה. חיבור חשבונות VMS עצמאיים באמצעות JWT אינו כלול בגרסה.
