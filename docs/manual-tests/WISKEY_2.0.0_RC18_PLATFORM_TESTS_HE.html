לפני השדרוג

שמור גיבוי מלא. אין שינוי בסכמת מאגר האנשים מ־rc.17. הורדת ארכיון או הגדרות אינה גיבוי מלא. מדיניות אירועים יכולה למחוק רשומות ולכן כדאי להוריד ארכיון לפני קיצורה.

חיבור webhook כבוי כברירת מחדל. אישור כפול פעיל חוסם החלת צי חדשה. אין צורך לפתוח דלת, להחליף ציוד או לשלוח הודעה כדי לבדוק ניווט ושמירה.

מה נבדק עבורך

שמירה אטומית, ביטול סקירה ישנה, בידוד הרשאות וחשבונות, המשך אחרי כשל תחנה, אירוע שנקלט בזמן כתיבת מדיניות, בחירת תבנית, קישור מזוהה, חתימה ושינוי קובץ, סינון סודות, הגבלת יומן וייבוא ממופה. בדיקות הממשק כוללות דפדפנים שונים ונייד.

הציוד מדומה בבדיקות האוטומטיות. איכות שמיעה, כתיבה ואימות של תחנה אמיתית ושחזור שרת מלא דורשים בדיקת קבלה. בדיקות שכבר אישרת אינן מאופסות.
