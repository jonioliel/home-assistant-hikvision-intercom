smplwise access control · 2.0.0-rc.22

החלפה והוצאה משימוש — קבלה ממוקדת

בדיקות תוכנה אוטומטיות נעשו על סימולטורים. הבדיקות הפיזיות להלן מיועדות לחלון תחזוקה עם ציוד מתאים.

מה כבר נבדק

העברה אטומית של קבוצות וחריגים, חסימות אישיות, כשל שמירה, נתק/תגובה אבודה, אישור כפול, סירוב לחשבון מוגבל, יומני ביטול, אימות תוכן מלא ופקדי נייד. אין צורך לחזור על בדיקות אלו ידנית כדי להגדיל את הרשימה. תוצאת השערים המדויקת רשומה ביומן המסירה.

מסמך הבדיקות המאוחד לימים האחרונים נשאר ממתין לבקשתך. הוראות ומגבלות

1. התאמת תוכנית למתקן קריאה בלבד

כלי ניהול ← ניהול צי ודוחות. בחר מקור וחלופה פנויה, סקור והכן תוכנית. ודא שהמיפויים הפיזיים, הקבוצות, החסימות ושמות התחנות נכונים. קרא את התוכנית השמורה; הכנה וקריאה בלבד לא צריכות לשנות גישה בתחנה.

2. העברה וביטול גישה במקור דורש ציוד וחלון תחזוקה

רק כאשר התחנה מיועדת באמת להחלפה ויש חלופה ריקה וממופה: החל את התוכנית. לאחר הסנכרון בדוק עובד בעל כרטיס או PIN בחלופה ובמקור. הגישה צריכה לעבוד בחלופה ולהידחות במקור. אדם חסום אישית צריך להישאר חסום גם בחלופה. ודא ששם ופרטי התחנה הועתקו. אם אין תחנה המיועדת להחלפה, סמן נדחה.

3. הוצאה משימוש והסרת חיבור רק לתחנה שפורשת בפועל

אם קיימת תחנה לפרישה, הכן תוכנית ללא חלופה והחל אותה. השאר את המקור מחובר עד שמופיע אימות ניקוי. ודא שקוד/כרטיס מנוהל נדחה בפועל, לחץ אימות ואז הסרת חיבור באישור נפרד. המסלול אינו מאפס את המכשיר ואינו מוחק קודים ציבוריים. אין צורך לפרוש תחנה פעילה כדי לבצע בדיקה.
