בדיקות קצרות: דוח חריגות

בדיקות הדוח, הסינון והדפדוף עברו אוטומטית. נותר לוודא שהנתונים תואמים לאירועים בתחנות שלך.

לאחר העדכון

בדיקות קודמות שעדיין ממתינות לך

בדיקת בריאות הצי והבחירה בין וידאו לתמונות, ובדיקת גישה זמנית נשמרו במסמכים הקודמים.

דיווח תוצאה

אם סעיף נכשל, שלח את המסך, הפעולה, התוצאה שציפית לה ומה שהתרחש. אין צורך לשלוח PIN, מספר כרטיס או סיסמה.

הדוח מונה רק אירועים שנקלטו ונשמרו. הוא אינו קובע שאירועים שלא מופיעים לא התרחשו.

הסימונים נשמרים בדפדפן הזה בלבד.
