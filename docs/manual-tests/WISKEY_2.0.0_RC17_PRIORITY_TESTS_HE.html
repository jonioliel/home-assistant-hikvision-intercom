מה נוסף

צבעים מובילים, עבודות ייבוא עם נקודת המשך, גיבוי מוצפן, הרשאות לכל שדה וקבוצות תחנות, הגנת מסך, אישור כפול, העברות ומלאי כרטיסים, תבניות עובדים ותזכורות וחידוש תוקף.

הוראות ותנאי הפעלה מלאים · כל הבדיקות הפתוחות מהסבבים הקודמים

לפני השדרוג

שמור גיבוי מלא של תשתית המערכת, התצורה, האחסון וקבצי האינטגרציה. מאגר האנשים עובר לסכמה 13. חזרה מחייבת את הגיבוי שלפני השדרוג ואת הקוד התואם יחד; התקנת קוד ישן בלבד אינה נתמכת.

נעילה, אימות נוסף ואישור כפול כבויים כברירת מחדל. להפעלתם יש לוודא חשבונות מקומיים עם סיסמה; לאישור כפול נדרשים שני מנהלים נפרדים. אין צורך לפתוח דלת או לשלוח הודעה אמיתית כדי לבדוק את התוכנה.

מה נבדק עבורך

מעבר סכמות 1–13, שמירת נתונים, התנגשויות גיבוי, סיסמה שגויה וקובץ ששונה, הרשאות, אי־אפשרות לאשר לעצמך, שמירה אטומית, ביטול והמשך עבודות, העברת כרטיס לאחר נתק ואובדן אישור, ותאימות הממשק למחשב ולנייד. פרסום הגרסה מותנה בבדיקות התוכנה בתהליך השחרור.

בדיקות התחנות האוטומטיות משתמשות במדמה ISAPI. שמיעה וקריאת כרטיס פיזיות ושחזור שרת מלא אינם מוכחים בבדיקות אלו. תוצאות שכבר אישרת לא אופסו.
