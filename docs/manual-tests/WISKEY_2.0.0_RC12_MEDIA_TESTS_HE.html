אין צורך לחזור על בדיקה שכבר אישרת באותו ציוד ובאותו מסלול, אלא אם השתנה משהו או נמצאה תקלה.

דיווח תוצאה

אם סעיף נכשל, ציין את התחנה, המכשיר, הדפדפן, הפעולה והתוצאה. לצורך שמע אפשר לצרף את קובץ האבחון; אין צורך לשלוח סיסמה, PIN או מספר כרטיס.
