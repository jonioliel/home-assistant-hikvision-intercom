הרשאות מפעילים — בדיקת ההתקנה שלך

תחנות מותרות, שדות לצפייה או לעריכה, כרטיסים, התראות ושעונים. ארבע הבדיקות הראשונות מספיקות לקבלת השדרוג; היתר לפי השימוש שלך.

מה משתנה

אפשר להגביל כל מפעיל לתחנות נבחרות ולקבוע בנפרד גישה לטלפון, לתמונה, לאמצעי זיהוי, לשדות מותאמים ולהרשאות כניסה. ברירת המחדל של ההרשאות הקיימות נשמרת. אדם שמשויך גם לתחנה מחוץ לתחום המפעיל מוגן מעריכה, כולל כשהסרת ההרשאה מהציוד עדיין ממתינה.

כל ערכות העיצוב, מסלולי המדיה, התזמונים והנתונים נשמרים. השם הטכני hikvision_intercom נשאר ואין צורך להסיר את האינטגרציה.

לפני השדרוג

שמור גיבוי תצורה מלא. מאגר האנשים נשאר בסכמה 11; מאגר הרשאות המפעילים מקבל סכמה 2 בשמירת שינוי. חזרה לגרסה ישנה דורשת גיבוי תואם, לרבות הרשאות המפעילים.

בדיקות אלה מתייחסות לממשקי WisKey בלבד. ישויות וממשקים אחרים בתשתית המערכת משתמשים בהרשאות שלהם. אין צורך לחזור על בדיקות תוכנה, שליחת הודעות, פתיחת דלת או בדיקות שמע שכבר אישרת רק בגלל עדכון זה.

הבדיקות שבוצעו עבורך

אימות הרשאות בצד השרת ובתעבורת תשתית המערכת; סינון לפני חיפוש, ספירה ודפדוף; שמירה בלי למחוק שדות מוסתרים; הגנת זהות משותפת; ביטול איסוף כרטיס ומדיה עם הסרת הרשאה; פקדי תחזוקה ושעון; תאימות למנהלים ולהרשאות הקודמות; בדיקות מחשב ונייד ודפדפנים.

בדיקות הציוד משתמשות במדמים. הן אינן הוכחת פתיחה פיזית, קריאת כרטיס בקורא שלך או קול ברמקול. תוצאות הסבב נרשמות גם במסמך הפיתוח.
