בדיקות קצרות להתקנה החיה

רק בדיקות שתלויות בדפדפן, בקצב הרשת או בתחנות שלך. בדיקות הקוד והמסכים מבוצעות אוטומטית.

תצוגת מרכז הכניסה — חובה לגרסה זו

גישה זמנית — רק עם משתמש בדיקה

בחר אדם וקוד בדיקה, דלת מתאימה וטווח קצר. מחוץ לטווח הזמן התחנה צריכה לדחות את הגישה; בדיקת UI או סטטוס ״מסונכרן״ לבדם אינם הוכחה לכך.

תצפית וחקירה

דיווח תוצאה

אם סעיף נכשל, שלח את שם התחנה, שם המסך, מה ציפית ומה קרה בפועל. לצילום בעיית שמע ציין מחשב/נייד ודפדפן. אין צורך לשלוח PIN, מספר כרטיס או סיסמה.

הסימונים נשמרים בדפדפן הזה בלבד. פירוט הסבב והמשימות שנותרו במסמך ההתקדמות.
