תמונת אדם מקובץ וחיתוך — rc.28

הבדיקות האוטומטיות מכסות פורמטים, חיתוך ופיקסלים, שמירה מפורשת, קבצים לא תקינים, הרשאות, ביטול ומשאבי מצלמה. נשארת בדיקת נוחות אחת בהתקנה שלך; אין צורך בפתיחת דלתות או שמע.

בחירת תמונה פרטית וחיתוך

בעריכת אדם בדיקה, בחר תמונה מקובץ. התאם הגדלה ומיקום עד שהתצוגה המקדימה נעימה וברורה. לחץ השתמש בתמונה, שמור את האדם ופתח שוב. ודא שהתמונה נשמרה בחיתוך שבחרת; אם נוח, נסה גם בנייד ותמונה המצולמת במצב אנכי. אפשר לבטל לפני שמירה כדי לשמור את התמונה הקודמת. צילום מצלמה והסרה עדיין זמינים. אין צורך לסנכרן לתחנות.

מסמך הבדיקות המאוחד לימים האחרונים נשאר ממתין לבקשתך.
