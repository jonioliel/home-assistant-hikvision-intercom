בדיקות מסירה לעיצוב החדש

העיצוב החדש נוסף לבחירה. יש לבצע את הבדיקות במערכת Home Assistant המותקנת. הבדיקות האוטומטיות של הממשק והשרת אינן מחליפות אימות וידאו, שמע ופתיחת דלת מול ציוד אמיתי. אין צורך לשנות הרשאות או למחוק משתמשים רק בשביל הרשימה הזאת.

התוצאות נשמרות בדפדפן הזה בלבד. ניתן להוריד דוח JSON ללא סיסמאות, PIN או מספרי כרטיסים. כל הבדיקות הפתוחות הקודמות.
