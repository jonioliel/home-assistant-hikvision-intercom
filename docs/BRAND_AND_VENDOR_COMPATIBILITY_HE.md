# מיתוג smplwise access control ותאימות התקנות קיימות

השם הגלוי של האינטגרציה ב־Home Assistant וב־HACS הוא **smplwise access control**. שם הממשק נשאר **WisKey**. המזהה הטכני `hikvision_intercom` נשמר בכוונה: תיקיית `custom_components`, ה־domain ב־manifest, רשומות התחנות, השירותים, פקודות WebSocket, נתיבי API, הפאנל וקובצי הנתונים הפרטיים משתמשים בו גם ב־2.0.0-rc.2. לכן התקנה קיימת מתעדכנת ב־HACS ללא מחיקה או מעבר נתונים.

גרסת 2.0.0-rc.1 ששינתה את המזהה הטכני אינה מתאימה לעדכון התקנה קיימת. אם HACS הציגה `No manifest.json file found`, פעל לפי [מדריך ההתאוששות](HACS_DOMAIN_MIGRATION_HE.md) ובחר במהדורה המתקנת. אין למחוק את האינטגרציה מתוך ״מכשירים ושירותים״.

## הכנה ליצרנים נוספים

שמירת `hikvision_intercom` כמזהה טכני אינה הופכת פקודות ISAPI לתואמות יצרנים אחרים. ממשק WisKey וליבת ניהול הגישה יכולים להישאר בעלי שם ניטרלי, ובשלב נפרד ניתן להוסיף מתאם פרוטוקול ל־Akuvox או ליצרן אחר. כל מתאם יצהיר על יכולות המכשיר בפועל — ממסרים, משתמשים, PIN, כרטיסים, אירועים, וידאו, שמע ולוחות זמנים — ויתרגם פעולות ושגיאות לליבה.

לפני הפעלת יצרן נוסף יש לבדוק תחנת Hikvision קיימת לצד תחנת היצרן החדש באותה התקנה, כולל הרשאות, סנכרון חלקי, ניתוק והתאוששות. הרחבה כזו לא תשנה את מזהי התחנות והישויות הקיימים ולא תניח שפעולה מסוימת זמינה בכל פרוטוקול.

## בדיקות תאימות לשדרוג

1. HACS מזהה `custom_components/hikvision_intercom/manifest.json` בתג הגרסה.
2. אותם מזהי תחנות, ישויות, משתמשים ונתוני הרשאות נטענים אחרי אתחול HA.
3. נתיבי הפאנל, WebSocket, השירותים, המצלמה והשמע נשארים בשם הטכני הישן.
4. השם הגלוי ב־HA/HACS הוא smplwise access control והממשק מציג WisKey.
