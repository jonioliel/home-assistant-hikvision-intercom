# עדכוני WisKey ב־Home Assistant

WisKey מתפרסמת כ־GitHub Release עם תג גרסה סמנטי לאחר שכל בדיקות השחרור עברו. HACS מספקת ישות עדכון למאגר ומציגה גרסאות חדשות במסך **הגדרות → עדכונים**. אין צורך ברענון ידני לשם זיהוי תקופתי. [תיעוד העדכונים של HACS](https://hacs.xyz/docs/use/update/).

## הגדרה חד־פעמית לגרסאות הנוכחיות

1. ודא שהמאגר `jonioliel/home-assistant-hikvision-intercom` מותקן ב־HACS. שמו שם עשוי עדיין להיות **Hikvision Intercom Manager**; שם המערכת הוא **WisKey**.
2. עבור אל **הגדרות → מכשירים ושירותים → HACS**, ופתח את מכשיר המאגר. אתר את ישות **Pre-release / גרסאות קדם**. אם היא מושבתת, הפעל אותה בהגדרות הישות, ואז העבר את המתג למצב פעיל.
3. ודא שגם ישות ה־**Update / עדכון** של אותו מאגר מופעלת. אם בחרת בעבר לדלג על הגרסה, בטל את הדילוג במסך העדכון.
4. השאר את HACS פועלת. לאחר בדיקת המאגר הבאה, גרסה חדשה תופיע ב־HA ותוכל להתקין אותה משם. לאחר ההתקנה יש לאתחל את Home Assistant כדי לטעון את הקוד החדש.

המתג נדרש מפני ש־`0.33.0-beta.1` וגרסאות ה־Alpha הקודמות מפורסמות כגרסאות קדם. הוא מאפשר את גילוין; הוא אינו מתקין אותן אוטומטית. מזהי הישויות נקבעים בהתקנה שלך, ולכן אין להעתיק מזהה ישות משוער. [מתג גרסאות קדם](https://hacs.xyz/docs/use/entities/switch/), [ישות העדכון](https://hacs.xyz/docs/use/entities/update/).

## מתי העדכון יופיע

HACS בודקת את GitHub במחזוריות. פרסום Release אינו שולח הודעת Push ישירה להתקנת HA. במקור HACS שנבדק ב־10 בספטמבר 2026, בדיקת המאגרים המותאמים שכבר הותקנו מתוזמנת אחת ל־48 שעות. לכן הופעת העדכון עשויה להתעכב עד המחזור הבא, ובמקרה של ניתוק או הגבלת GitHub גם מעבר לכך. הגרסה והתזמון של HACS בהתקנה שלך עשויים להיות שונים. [מנגנון התזמון במקור HACS](https://github.com/hacs/integration/blob/main/custom_components/hacs/base.py).

מאגר WisKey הוא מאגר מותאם. HACS שולפת את המידע עליו מ־GitHub; רענון ידני באמצעות **Update information** הוא קיצור דרך לבדיקה מיידית, ולא דרישה לכל עדכון. [מקורות הנתונים של HACS](https://hacs.xyz/docs/faq/data_sources/).

אין להשתמש באוטומציה של `homeassistant.update_entity` כהבטחה לבדיקה שעתית של המאגר: במימוש ישות המאגר של HACS שנבדק, הפעולה אינה מבצעת שליפת מטא־נתונים חדשה. לא נוסף מנגנון שתלוי בממשקים פרטיים של HACS או שמשנה את העדפות ההתקנה ללא בחירה. [מימוש הישות](https://github.com/hacs/integration/blob/main/custom_components/hacs/entity.py).

## בדיקה במקרה שאין התראה

בדוק שהישות אינה מושבתת או לא זמינה, שמתג גרסאות הקדם פעיל, ושאין שגיאת התחברות או הגבלת קצב ביומן HACS. גרסה שהותקנה ידנית מתיקייה או מ־commit עשויה לדרוש בחירת תג Release פעם אחת דרך HACS. בחר בתג `v0.33.0-beta.1` לגרסת ה־Beta, ולא במזהה commit מקוצר.

הפרסום והתג נבדקים מרחוק כחלק מהשחרור. הפעלת מתג גרסאות הקדם והופעת ההתראה בהתקנת HA של הבעלים לא אומתו מרחוק; המסמך מתאר את התנהגות HACS וההגדרה הנדרשת, ולא שינוי שכבר בוצע בשרת.
