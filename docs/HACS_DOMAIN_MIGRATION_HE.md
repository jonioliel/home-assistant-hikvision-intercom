# התאוששות משגיאת HACS ב־v2.0.0-rc.1

## מה קרה

התג `v2.0.0-rc.1` החליף את תיקיית `custom_components/hikvision_intercom` בתיקייה בשם אחר. התקנת HACS קיימת ביקשה את `custom_components/hikvision_intercom/manifest.json` ולכן ההורדה נכשלה עוד לפני טעינת קוד האינטגרציה. זו הייתה שגיאת אריזה ושחרור שלנו, לא תקלה בתחנת האינטרקום או בנתוני המשתמשים.

בהתאם להחלטת בעל המערכת, **המזהה הטכני `hikvision_intercom` נשאר קבוע**. גרסת `v2.0.0-rc.2` מתקנת את מבנה המאגר ומשאירה את שם המוצר הגלוי **smplwise access control / WisKey**. אין צורך בכלי הסבת domain, בהסרת רישום HACS או במחיקת האינטגרציה מתוך HA. [כללי מבנה מאגר HACS](https://www.hacs.xyz/docs/publish/integration/).

## התקנת המהדורה המתקנת

1. ודא שהתחנות והנתונים הקיימים עדיין מופיעים ב־WisKey. אם ניסיון ההתקנה הקודם נכשל לפני הורדת הקוד, המהדורה המקומית אמורה להישאר כפי שהייתה; אם אינך רואה את הנתונים, עצור לפני פעולות נוספות.
2. שמור גיבוי HA עדכני לפני השדרוג. אין צורך ב־Samba: **הגדרות ← מערכת ← גיבויים ← הצג את כל הגיבויים ← הורדה**. אם אין גיבוי מלא עדכני, צור אותו דרך **גבה כעת ← גיבוי ידני**. קובץ ההורדה מכיל פרטי גישה רגישים; שמור אותו בפרטיות. [הוראות Home Assistant](https://www.home-assistant.io/common-tasks/general/#downloading-your-local-backups).
3. לאחר פרסום `v2.0.0-rc.2`, פתח ב־HACS את המאגר `jonioliel/home-assistant-hikvision-intercom`, בחר **Download/Redownload** ואת התג `v2.0.0-rc.2`. אם גרסאות קדם אינן מוצגות, הפעל את מתג Pre-release של המאגר. אין לבחור שוב ב־`v2.0.0-rc.1`.
4. הפעל מחדש את Home Assistant. בדוק שמספר התחנות, המשתמשים, הכרטיסים, הקבוצות, ההרשאות, האירועים, תוכניות הדלת והשמע נשמר; בדוק תחילה תחנה אחת לפני סנכרון כולל. [רשימת בדיקות השדרוג](manual-tests/SMPLWISE_HACS_UPGRADE_TESTS_HE.html).

**אל תמחק את האינטגרציה** ב״הגדרות ← מכשירים ושירותים״ לצורך תיקון שגיאת HACS. מחיקת רשומות התחנות אינה נדרשת ועלולה לשבור מזהי ישויות ואוטומציות. אם HACS עדיין מחזירה שגיאת manifest גם בבחירת `v2.0.0-rc.2`, העתק את נוסח השגיאה המלא ועצור; אין לערוך ידנית את קובצי `.storage`.
