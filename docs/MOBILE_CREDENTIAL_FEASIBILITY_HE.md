# WisKey — היתכנות מפתח נייד ו־Hik-Connect

בדיקה: 10 בספטמבר 2026. משימת 40 בתוכנית המאושרת.

**החלטה:** לא להפעיל רישום NFC נייד או חיבור Hik-Connect מתוך WisKey ב־Beta זו. נמצא מסלול אינטגרציה רשמי לענן Hik-Connect for Teams, אך לא נמצא חוזה מאומת להנפקת מפתח NFC ל־DS-KV6124-E1 בסביבה הנוכחית. זו מסקנת היתכנות מוגבלת לראיות שבידינו, לא טענה שאין ליצרן יכולת כזו בשום דגם.

דף הנתונים לדגם מפרסם כרטיסי M1 בתדר 13.56 MHz ושימוש ב־Hik-Connect; הוא אינו מספק חוזה API להנפקת מפתח NFC לטלפון. ציון Hik-Connect כשיטת פתיחה אינו מוכיח שהטלפון פועל ככרטיס מול הקורא. [דף נתוני DS-KV6124-E1](https://assets.hikvision.com/prd/normal/all/doc/m000168989/DS-KV6124-E1_Datasheet_20260603.pdf).

תיעוד היצרן אכן מתאר הגנת NFC שמאפשרת רק אישורים שמקורם ב־Hik-Connect. אולם דף הדגמים של אותו מדריך מתייחס למשפחת **DS-K1T670**, ולכן אין להעביר את ההוראה ל־DS-KV6124-E1 על סמך שם היצרן בלבד. [הגנת NFC](https://enpinfo.hikvision.com/hkwsen/unzip/20251224164304_81809_doc/GUID-BF7E94ED-6E89-4639-A5B7-D840D48724AC.html), [הדגמים הכלולים במדריך](https://enpinfo.hikvision.com/hkwsen/unzip/20251224164304_81809_doc/GUID-D929B9F9-8D9F-4EC5-9E6C-4C350B676189.html).

תוכנית השותפים מציגה OpenAPI ל־Hik-Connect for Teams, בקשת AK/SK, רישום מכשירים והגדרת הרשאות בפלטפורמה. מוצגים מסלולי אינטרקום עם וידאו, שמע, פתיחה ושילוב SDK למפתח Bluetooth; זה אינו חוזה NFC מקומי ב־ISAPI. חלק מהפרטים מצריכים התחברות, ובמסלול בקרת הגישה מוזכרים גם רישיון ופנייה ליצרן. [מסלול האינטגרציה הרשמי](https://tpp.hikvision.com/products/HC-Integration).

## תנאי פתיחת מימוש עתידי

1. אישור יצרן לדגם, לקושחה, לאזור השירות ולסוג חשבון הלקוח.
2. מסמכי OpenAPI/SDK רשמיים עם זכאות שימוש ובדיקת הנפקה וביטול במכשיר ניסוי.
3. החלטה מפורשת של הבעלים אם להוסיף תלות בענן, חשבון ורישוי; אין רכישה או שיוך חשבון בשלב זה.
4. חוזה תחזוקה למזהה המפתח ולביטולו, הרשאות מינימליות, אחסון סודות בצד HA ובדיקת התנהגות בעת ניתוק.

אין שינוי ב־ISAPI, בהגדרות NFC, בכרטיסים קיימים או בחשבונות הבעלים בעקבות מחקר זה. פתיחת הדלת מתוך ממשק HA הקיים ממשיכה במסלול שכבר אומת.
