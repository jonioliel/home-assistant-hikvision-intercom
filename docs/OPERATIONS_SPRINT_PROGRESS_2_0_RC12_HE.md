# התקדמות סבב התפעול — 2.0.0-rc.12

הסבב התקדם בסדר שבחר הבעלים: **5 → 1 → 2 → 4 → 3**. בחירת תצוגת מרכז הכניסה נכנסה בתחילת הסבב ונכללת בכל הגרסאות הבאות.

| סדר | מסירה בסבב | מה נשאר מעבר למסירה זו |
| --- | --- | --- |
| 5 · גישה זמנית | אשף עם טווח תוקף, PIN ייחודי או כרטיס ודלתות; סיווג עובד/אורח/קבלן; אחראי ומטרת ביקור; אימות בשרת והעברה ב־CSV. | אישור מארח, צ'ק־אין/יציאה ומחזור חיים ייעודי לאורח. שינויי גישה בפועל נשארים במסלול הסנכרון הקיים. |
| 1 · בריאות צי | היסטוריה מוגבלת לשבעה ימים, סיכום צי וסינון תחנות שדורשות טיפול, עם סיבות נפרדות לקשר, סנכרון ושעון. | התראות מתמשכות, ספי שירות ותרגיל יציבות בצי האמיתי. |
| 2 · חקירת אירועים | קיצורי סינון, סיכום חריגות נצפות ודירוג תחנות עם מעבר ישיר לאירועים המתאימים. | ציר זמן רב־מקורי, תיק חקירה וקורלציה בין תחנות. |
| 4 · הרשאות מפעילים | תבניות תפקיד ותצוגה מקדימה מחושבת בשרת לפני שמירה, לפי אותן הרשאות אזורים שנאכפות בפועל. | הרשאות נפרדות לפי תחנה, פעולה ושדה. התצוגה אינה מציגה מגבלות שטרם נאכפות. |
| 3 · מדיה | תצוגת יכולות נפרדת ואבחון ראיות בנגן: וידאו, שמע נכנס ושמע יוצא; זמן דגימה, קודק וריצוד RTC כשזמינים, ללא הקלטת תוכן. | בדיקה מלאה מקצה לקצה, בחירת התקן פלט נתמכת ומדידת השהיה. שמיעה פיזית מחייבת בדיקת בעלים. |
| תצוגת מרכז הכניסה | הגדרה מרכזית: וידאו חי ללא קול או תמונה שמתעדכנת כל עשר שניות כשהיא מוצגת. לחיצה על התמונה פותחת מצלמה חיה. | אימות התעבורה והנוחות בחיבור האטי של האתר. |

המסירות נוספו לעיצובים ולמסלולים הקיימים. מזהה `hikvision_intercom`, מאגרי המשתמשים והרשאות הדלתות לא שונו בגלל בחירת תצוגה או רענון אבחון. הבדיקות האוטומטיות אינן מחליפות אישור ציוד פיזי.

[מסמך הבדיקות המצטבר לסבב](manual-tests/WISKEY_2.0.0_RC12_MEDIA_TESTS_HE.html) מפנה לבדיקה הקצרה בכל תחום. בדיקות שטרם התקבלה לגביהן תוצאה נשארות פתוחות ולא מסומנות כעברו.
