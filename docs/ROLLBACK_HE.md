# חזרה בטוחה לגרסה קודמת של WisKey

מסמך זה מתאר חזרה מגרסה חדשה של WisKey לגרסה יציבה קודמת דרך HACS. הפעולה מחליפה את קובצי
האינטגרציה ב־Home Assistant. היא אינה שולחת פקודה לאינטרקום ואינה מחזירה הגדרות שכבר נכתבו
פיזית לתחנה.

## לפני שדרוג

1. בכלי ניהול ← בריאות ובדיקות שטח, הפעל **בדיקת מוכנות לשדרוג**.
2. הורד **מלאי תחנות JSON** ו־**חבילת תמיכה** ושמור אותם מחוץ ל־Home Assistant.
3. צור גיבוי מלא של Home Assistant והמתן לסיום הגיבוי.
4. ודא שאין סנכרון משתמשים, ייבוא CSV, הודעת TTS או שיחת שמע פעילים.
5. רשום את גרסת WisKey הנוכחית ואת גרסת Home Assistant.

אזהרה על תחנה מנותקת או סנכרון ממתין אינה בהכרח חוסמת שדרוג, אך יש לסיים או לתעד את העבודה
לפני האתחול. כשל אחסון או מבנה הגדרות שאינו נתמך חוסמים שדרוג עד לתיקון.

## חזרה דרך HACS

1. פתח HACS ← Integrations ← WisKey.
2. פתח את תפריט הפעולות ובחר **Redownload**.
3. בחר גרסת Release קודמת מפורסמת. אין לבחור hash של commit.
4. אשר הורדה והמתן לסיום.
5. אתחל את Home Assistant.
6. פתח הגדרות ← מערכת ← תיקונים וודא שלא הופיע Repair חדש של WisKey.
7. פתח WisKey ובדוק את הגרסה המוצגת.

## בדיקת קבלה לאחר חזרה

בצע תחילה בדיקות שאינן משנות ציוד: טעינת המסכים, רשימת התחנות והמשתמשים, אירועים, תמונת מצלמה,
הרשאות משתמשי HA ודוחות. אחר כך בדוק תחנה אחת: פתיחת דלת, סנכרון משתמש קיים ושמע. רק לאחר
שהתחנה הראשונה תקינה המשך לכל התחנות.

אם הגרסה הישנה אינה מכירה שדה חדש, אל תמחק את השדה ואל תיצור את המשתמש מחדש. חזור לגרסה
החדשה או שחזר את גיבוי Home Assistant שנוצר לפני השדרוג.

## שחזור גיבוי

אם האינטגרציה אינה נטענת גם לאחר בחירת Release קודם:

1. עצור ניסיונות עריכה וסנכרון.
2. שחזר את גיבוי Home Assistant המלא מלפני השדרוג.
3. אתחל ובדוק שהגרסה, המשתמשים וההרשאות חזרו.
4. הורד חבילת תמיכה חדשה והשווה אותה לדוח שנשמר לפני השדרוג.
5. דווח על התקלה בלי לצרף סיסמה, PIN, מספר כרטיס מלא או כתובת תחנה.

## גבולות השחזור

- גיבוי Home Assistant מחזיר את נתוני WisKey המרכזיים למועד הגיבוי.
- שינוי שכבר הושלם ואומת בתחנה עשוי להישאר בתחנה גם אחרי שחזור HA.
- לאחר שחזור יש לבצע סריקת יכולות וסנכרון מבוקר מול תחנה אחת לפני סנכרון כללי.
- תוכניות פתיחה המנוהלות ב־HA תלויות במצב ששוחזר; לוחות מקומיים, אם נתמכים ונכתבו לתחנה,
  דורשים קריאה ואימות מהתחנה.
