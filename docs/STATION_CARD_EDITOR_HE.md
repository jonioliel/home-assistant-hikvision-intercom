# קריאת כרטיס מהאינטרקום מתוך עריכת משתמש — 0.35.1-beta.1

הכפתור **קריאת כרטיס מהאינטרקום** הועבר מהפעולות הכלליות למקטע **כרטיסים** בעריכת המשתמש, ליד הוספה ידנית וקורא USB. קורא USB אינו מחליף את קריאת הכרטיס מהתחנה.

1. פתח משתמש קיים דרך **עריכה** ושמור שינויים שטרם נשמרו.
2. במקטע **כרטיסים** בחר **קריאת כרטיס מהאינטרקום**.
3. בחר תחנה וקורא, והתחל איסוף כרטיס.
4. הצמד את הכרטיס לקורא בתחנה, בדוק את התוצאה ואשר את השיוך.

במשתמש חדש הכפתור מוצג עם הסבר שיש לשמור תחילה את המשתמש. אין שמירה שקטה או מחיקת שינויים בטופס. תהליך בדיקת יכולות הקורא, הביטול והאישור המפורש נשאר ללא שינוי; אין שינוי באחסון או ב־ISAPI.

בדיקות חדשות מוודאות את מיקום הכפתור ליד USB ברוחבי 390/1440, פתיחת בחירת התחנה ללא התחלת איסוף אוטומטי, והגנה על שינויים לא שמורים. בדיקות האיסוף הקיימות כוללות תוצאה מוסווית, אישור מפורש, ביטול ותגובה מאוחרת. בדיקה פיזית של הצמדת כרטיס לא בוצעה במסגרת תיקון הממשק.

פורסמה גרסת [0.35.1-beta.1](https://github.com/jonioliel/home-assistant-hikvision-intercom/releases/tag/v0.35.1-beta.1), commit `237aa1e`. כל שבע בדיקות ההפצה עברו: 1,021 בדיקות Python בכל גרסה, 314 בדיקות HA ו־372 בדיקות דפדפן.
