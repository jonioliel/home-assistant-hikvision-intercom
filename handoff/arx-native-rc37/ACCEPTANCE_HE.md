# בדיקות קבלה לשילוב WisKey מקורי ב־Arx

מטרת הרשימה היא להפריד בין בדיקות תוכנה, בדיקות Docker/HA ובדיקות ציוד אמיתי. לכל שורה יש לצרף תוצאה בפועל, גרסאות, תאריך וראיה. אין לסמן “עבר” על סמך קוד שנכתב בלבד.

## 1. פריסה וזהות

- [ ] אותרו גשר HA ואינטגרציית Arx הקיימים, ונרשם איזה רכיב מטפל באימות, WebSocket, מדיה ואירועים; לא נוצר חיבור כפול שלא לצורך.
- [ ] נבדקו כתובת HA ו־WebSocket מתוך קונטיינר התוסף, Ingress, TLS והרשאות רשת.
- [ ] חשבון מפעיל רגיל וחשבון מנהל מזוהים כחשבונות HA הנכונים ב־`authorization/session`; שינוי משתמש מנקה מידע קודם.
- [ ] משתמש שאין לו הרשאה אינו רואה נתוני WisKey או מדיה ואינו יכול להפעיל פקודות דרך API Arx ידני.
- [ ] `SUPERVISOR_TOKEN`, refresh tokens, PIN, כרטיס מלא ו־RTSP credentials אינם מופיעים בדפדפן, בכתובת, בלוגים או בצילומי מסך.
- [ ] ניתוק, logout ושינוי הרשאות סוגרים WebSocket ומדיה; `access_revoked` מנקה cache ונתונים פרטיים.

## 2. תצוגה וניווט

- [ ] WisKey מוצג כחלק ממסכי Arx בלי iframe, סרגל WisKey כפול או גלילה אנכית כפולה.
- [ ] Overview, אנשים, דלתות/תחנות, פעילות וניהול מציגים נתונים ופעולות לפי יכולות והרשאות מפעיל; מצבי שגיאה/אין נתונים אינם ריקים סתם.
- [ ] כניסה ל־URL ישיר, רענון, חזרה/קדימה וניווט בטלפון מחזירים למסך ולתחנה המתאימים.
- [ ] השוואה חזותית ב־390×844, 768×1024, 1440×900 ו־1920×1080, בהיר וכהה, כולל RTL.
- [ ] בדיקות עומס נתוני 1/4/8/12 תחנות וספריית אנשים גדולה אינן מושכות את כל רשימת המשתמשים בכל רענון.

## 3. פעולות ונתונים

- [ ] `overview.api.commands` ו־`authorization/session` שולטים בהצגת והפעלת כל פעולה; השרת בודק שוב ולא סומך על כפתור מוסתר.
- [ ] יצירת/עריכת אדם, PIN/כרטיס, קבוצות, לוחות זמנים וקודים ציבוריים עוברים דרך WisKey בלבד, עם revision ו־preview/confirmation הנדרשים.
- [ ] מצב “נשמר”, “ממתין לסנכרון”, “סונכרן”, “נכשל” ו־“אושר בשטח” מוצגים לפי ראיות נפרדות.
- [ ] פתיחת דלת היא פעולה מפורשת לממסר פיזי שנבחר; תשובה שנעלמה אינה מפעילה retry אוטומטי.
- [ ] משתמש ללא הרשאה, revision ישן, תחנה מנותקת, תשובה שאבדה ושינוי הרשאה באמצע פעולה נבדקו בפועל.

## 4. מצלמות, שמע ו־Companion

- [ ] מצלמה אחת חיה עובדת מתוך Arx בסביבת ההתקנה האמיתית, עם אימות ואיסוף משאבים בעת סגירה.
- [ ] לפחות 10 מצלמות חיות יחד בקיר Arx נבדקו על ציוד אמיתי במסגרת 1354×729; צוין מספר הזרמים שעבדו, מדיניות HLS/MSE/RTC ומכשירי בדיקה.
- [ ] מצב חיבור מעל התקציב מציג fallback או הודעה שימושית; אין שגיאת 429 חשופה כאריח שבור.
- [ ] האזנה, מיקרופון, TTS ושיחה נבדקו בנפרד; צוין במפורש אם אדם ליד תחנה שמע את הפלט.
- [ ] אפליקציית Companion נבדקה על טלפון אמיתי; הרשאות מדיה וחזרה מרקע נבדקו.

## 5. מסירה וחזרה

- [ ] Arx מספק commit/גרסה, רשימת קבצים ששונו, הוראות התקנה, תצורת Docker נדרשת, בדיקות ותצלומים.
- [ ] קיימת חזרה לגרסת Arx הקודמת בלי מחיקת נתוני WisKey; ה־iframe הישן זמין זמנית כנתיב חזרה עד קבלת שוויון.
- [ ] כל פער שנותר מסומן בגלוי, ובפרט אם לא הושלמו זהות מפעיל, 10 זרמים, שמע פיזי או Companion.
